### 技术方案

- **字体在线引用**：index.html 恢复 Google Fonts CDN（preconnect + css2?family=Noto+Sans+SC:wght@400;500;700&display=swap）；main.tsx 移除三个 `@fontsource/noto-sans-sc/*.css` 引入；package.json 移除 `@fontsource/noto-sans-sc` 依赖并 npm install 同步 lockfile（dist 产物不再打包字体 woff2）。字体栈变量 `@font-family-base` 不变。
- **列表占满剩余高度**（三层布局改造，页面层只需加一个类）：
  - `layout.less`：`.basic-layout__content` 改为定高 `calc(100vh - 56px)` + `overflow:hidden` + 纵向 flex；直接子元素（页面根节点，含 PageContainer 外层包裹 div）`flex:1; min-height:0; display:flex; flex-direction:column`，解决 `.ac-page` 等包裹层打断高度链的问题。
  - `PageContainer/index.less`：容器本身纵向 flex 撑满；`&__body` `flex:1; min-height:0; overflow:auto`——列表页由表格卡撑满，长表单/详情页内容区内部滚动，页面标题固定。
  - `global.less` 新增全局工具类 `.table-fill`：卡片 `flex:1; min-height:0; overflow:hidden`，兼容 antd Card 与模块自定义 div 卡片；内部 `.ant-table-wrapper → .ant-spin-container → .ant-table` 逐级 flex 传递，`.ant-table` 溢出滚动，`.ant-table-thead th` `position:sticky; top:0` 表头吸顶，分页 `.ant-pagination` 固定卡片底部。
- **统一分页**：27 个表格全部接入受控分页模板。17 个原 `pagination={false}` 的页面补 `page/pageSize` state 并替换；9 个已有分页的页面（assess/exception/followup×2/goal/leads/health/plan/work-order/warning）将 `const pageSize = 常量` 改为 `useState`，onChange 由 `setPage` 改为双参回写，showTotal 统一为「共 N 条」；exception/warning 的硬编码 total（49/18）改为 `filtered.length`，保证 mock 数据下翻页行为正确。各列表卡自定义页脚（共 N 条 x/y 页）随分页组件接入移除，仅保留提示性文字。

### 学习到的知识

- antd Table 不定死 `scroll.y` 也能「表头吸顶 + 表体滚动」：外层 flex 链（卡片 → wrapper → spin-container → table）传递高度 + `.ant-table { overflow:auto }` + `th { position:sticky; top:0 }`，比逐页算像素更通用
- 页面根节点不一定是 PageContainer（如 `.ac-page` 包裹层还含 Modal），布局高度链需在 content 的直接子元素层兜底（`> * { flex:1 }`）
- 受控分页 + 全量 mock 数据时 total 必须取 `filtered.length`：硬编码大 total（126/49/18）会导致第 2 页起无数据

### 遗留问题

- 字体改为在线引用后，内网/离线环境字体将回退到系统字体栈（PingFang SC / Microsoft YaHei）；如部署环境无法访问 Google Fonts，需换国内镜像 CDN
- 健康档案详情等 Tab 内嵌小表（用药记录/检查检验/历次测评）已接受控分页，但未加 table-fill（其高度由详情页内容区滚动管理，非整页列表场景）
