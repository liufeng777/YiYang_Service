# 工作日志 2026-11-10

## 任务1：健康档案、检测项管理与随访问卷接口更新

- 时间：2026-11-10
- 执行人：Kimi@Trae
- 类型：Swagger 对齐 / 页面重构 / 交互优化

### 任务描述

按最新版 `src/api/swagger.json` 更新接口与页面；优化健康档案主档案、生活习惯和慢病专病模块；移除健康指标中的字典入口；在健康档案列表增加独立的“检测项管理”页面。

### 技术方案

- **健康档案列表**：改用 `GET /api/v1/staff/health-archives`，展示会员、接入状态、最后编辑人和档案更新时间，修正性别与空年龄显示，并增加“检测项管理”入口。
- **主档案与生活习惯**：主档案改为紧凑四列表单；生活习惯按饮食、运动、睡眠、吸烟、饮酒、感官精神分组，补充响应式布局；四类病史统一读取分页响应的 `list`。
- **慢病专病**：保留专病列表、新建、控制状态变更、终止、评估列表/详情/编辑；新建和编辑评估均按病种指标字典动态生成表单，支持数值、枚举、多选、必填、单位和排序；已终止专病禁止重复变更或终止；无法识别的字典结构提供 JSON 录入兜底。
- **健康指标**：移除指标记录页的字典按钮与字典展示，仅保留检测项选择、指标记录新增/编辑和趋势查询；检测项下拉仍复用管理接口。
- **检测项管理**：新增隐藏菜单路由 `/health-record/metric-management`，实现分类树、分类增改/启停、检测项分页筛选、增改删/启停，以及参考范围和慢病关联配置。
- **随访同步更新**：列表状态改为 `1 待回访 / 2 已回访`，类型改为 `1 日常随访 / 2 健康预警回访`；创建预警随访提交 `warning_id`；执行页接入详情、模板、草稿保存和完成接口，支持子项、补充说明、随访结果和下次随访日期。

### 已修正的接口与 UI 不匹配

1. 健康档案列表不再复用健康服务接入名单，改用独立健康档案分页接口。
2. 健康指标不再承担检测项字典管理职责，管理功能迁移到独立页面。
3. 慢病评估不再只展示原始字典或固定字段，改为按病种字典生成动态表单。
4. 随访列表旧的本地姓名过滤和旧状态/类型枚举已移除，筛选参数与文档保持一致。
5. 随访执行不再只调用无请求体的完成接口，已接入新版详情、模板、草稿和带请求体的完成流程。

### 仍待后端明确的不匹配与不确定性

1. 慢病指标字典、随访详情/模板等响应仍声明为通用 `pkg.Response`，精确数据结构未定义；当前使用兼容解析，慢病字典无法识别时保留 JSON 兜底，随访问卷无子项时允许直接填写结果。
2. 随访保存/完成请求体只声明 `object`；当前按接口描述提交 `start_time / remark / next_followup_date / items / result`，字段名仍需真实请求样本或后端确认。
3. 检测项列表筛选文档写“停用 = 2”，但 `ReqStaffMetricStatus` 请求体写“停用 = 9”；页面分别按各自声明传值，建议后端统一枚举。
4. 主档案和生活习惯部分数值字段未提供枚举字典，仍保留编码输入，未虚构中文选项。
5. 本次只完成静态类型与生产构建验证，未连接真实后端进行接口联调。

## 任务2：检测项管理分类树与左右联动布局

- 时间：2026-11-10
- 执行人：Kimi@Trae
- 类型：页面布局 / 交互优化 / 表单统一

### 任务描述

将检测项管理页改为左右分栏：左侧使用 Tree 展示分类名称、编码和层级，悬浮显示操作入口；选中分类后右侧展示对应检测项；分类和检测项的新增、编辑统一使用 Drawer。

### 技术方案

- **左侧分类树**：使用 `Tree` 和 `showLine` 展示完整层级，节点同时展示名称、编码和停用状态，加载后展开全部分类；提供“全部检测项”入口和新增一级分类图标按钮。
- **悬浮操作**：分类节点悬浮时显示更多图标，通过 `Dropdown` 提供编辑、新增子类、启用/停用操作，触屏设备保持操作图标可见。
- **左右联动**：选中分类后将 `category_id` 传给检测项列表并回到第一页；右侧显示当前分类名称和编码，新增检测项默认归入当前分类。
- **Drawer 表单**：分类新增/编辑使用 480px Drawer，检测项新增/编辑使用 720px Drawer，底部统一提供取消、保存按钮及提交加载状态。
- **响应式样式**：桌面端左侧分类卡片吸顶、右侧列表自适应；窄屏切换为上下布局，移动端检测项表单改为单栏。
- **数据兼容**：分类接口同时兼容直接数组和 `{ list }` 返回结构，避免通用响应类型导致运行时空列表。
