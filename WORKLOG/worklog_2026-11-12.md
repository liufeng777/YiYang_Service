## 任务1：病史枚举彩色标签与全局表单抽屉改造

- 时间：2026-11-12
- 执行人：Kimi@Trae
- 类型：枚举渲染 / 表单交互 / 通用组件

### 任务描述

将健康档案病史记录中的枚举字段改为带颜色区分的 Tag 展示；将健康档案及整个项目中的新增、编辑类 `Modal + Form` 统一改为 `Drawer + Form`，删除、拒绝、终止和审核驳回等需要二次确认的操作继续保留 Modal。

### 技术方案

- **病史枚举标签**：在档案枚举工具中新增统一颜色映射，严重程度、疾病状态和手术结果按语义使用不同颜色，过敏类型、手术类型、亲属关系等按枚举值稳定区分颜色；病史表格通过枚举字典解析文案并使用 Tag 渲染。
- **通用表单抽屉**：新增 `FormDrawer` 组件，统一标题、开关、关闭、提交、加载、宽度及底部取消/保存操作，表单内容区域独立滚动，数字输入默认占满可用宽度。
- **新增编辑改造**：病史、慢病评估与专病、指标记录、健康目标与方案、检测项参考范围与慢病关联、健康会员、活动补登记与代报名、咨询人工回复等共 15 处表单改用 FormDrawer。
- **表单规范化**：活动补登记、代报名和咨询人工回复同步使用 `Form + Form.Item` 管理字段及校验，不再仅依赖非受控输入。
- **确认操作保留**：健康会员确认/拒绝接入、终止专病管理和订单审核不通过共 3 处确认类 Modal 保持不变；健康方案确认、放弃和删除继续使用 Popconfirm。

- `git diff --check`：通过，无空白错误；仅有 Git 的 LF/CRLF 转换提示。
- 全项目检查到 15 个 FormDrawer 使用点，分布于 9 个页面文件；保留的 3 个 Modal 均为确认或驳回类操作。
- 本次未连接真实后端，也未启动浏览器进行接口及交互联调。

## 任务2：健康指标参考范围、慢病关联指标与评估维护

- 时间：2026-11-12
- 执行人：Kimi@Trae
- 类型：趋势可视化 / 专病字典 / 评估 CRUD

### 任务描述

按趋势接口的 `series/points/ref_lower/ref_upper` 优化健康指标趋势 Drawer，根据正常范围标识测量点；恢复慢病专病的关联指标列表；在评估记录中提供新增评估和修改评估能力。

### 技术方案

- **趋势响应建模**：为趋势结果、指标序列和测量点补充明确 TypeScript 类型，优先解析接口声明的 `series` 结构，保留旧结构兼容解析。
- **正常范围判定**：测量值低于 `ref_lower` 显示为低于范围，高于 `ref_upper` 显示为高于范围，范围内显示正常；缺少上下限时才回退使用 `is_abnormal`。
- **趋势图优化**：正常区间使用浅绿色带展示，上下限使用虚线和文字标注，参考范围参与纵轴缩放；不同状态测量点使用不同颜色，Tooltip 展示测量时间、测量值、判定结果和正常范围。
- **趋势摘要与交互**：卡片增加最近记录、异常状态、参考范围、最高/最低/平均值和异常点统计；Drawer 增加指标/测量点摘要、最近一周/30 天/90 天快捷查询、自定义日期、多指标查询和图例。
- **关联指标恢复**：选中慢病卡片后请求 `/chronic-diseases/dict/{code}`，解析 `definitions` 并使用 small Table 展示名称、编码、单位、类型、必填、多值、派生、字典来源、参考范围、分组和排序；卡片列表与指标列表分区滚动，可收起。
- **评估新增/修改**：评估 Drawer 增加“新增评估”，列表操作提供“修改”；两种模式复用动态指标表单，新增默认当天和健管师录入，修改先取批次详情并回填；保存后刷新时间线和专病卡片统计。
- **类型修复**：补充字典派生、字典来源和参考范围字段，并修复病史编码条件渲染的严格类型问题。

### 接口与 UI 差异

1. 当前 Swagger 的 `/api/v1/staff/health-archives/chronic-diseases/{id}/assessments` 仅声明列表 `GET`，未声明新增 `POST`。本次按同一集合格径补充新增评估请求，参数复用 `shared.ReqArchiveChronicAssessment` 并通过 query 传递 `member_id`，需后端确认并同步文档。
2. 趋势和专病字典的 Swagger 200 响应仍引用通用 `pkg.Response`，具体结构来自本次提供的实际响应说明；前端已按实际结构建模，并保留必要的兼容解析。
3. 本次未连接真实后端验证新增评估 POST、参考范围边界值及派生指标重算结果。
