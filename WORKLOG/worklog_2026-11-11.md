## 任务1：健康指标趋势图与健康档案详情展示优化

- 时间：2026-11-11
- 执行人：Kimi@Trae
- 类型：数据可视化 / 页面优化 / 通用响应结构化

### 任务描述

参考用户提供的健康指标列表、指标趋势和健康档案示例图，以 Swagger 实际接口与返回数据为主，将健康指标趋势绘制成折线图，并优化健康档案详情其他页签的信息展示，不照搬示例数据或虚构业务字段。

### 技术方案

- **健康指标列表**：合并指标名称与编码，突出测量值和单位，异常值使用醒目状态；来源兼容名称与编码，行内增加“趋势与历史”入口并自动选中当前指标。
- **趋势查询**：保留多指标、时间范围和返回条数查询，趋势结果改为宽屏 Drawer，不再展示原始 JSON。
- **趋势可视化**：按接口说明读取各指标升序 `points`，使用原生 SVG 绘制响应式折线图、坐标网格、时间刻度和数据点悬浮提示，未新增第三方图表依赖。
- **趋势摘要与历史**：每个指标展示最近记录、最高值、最低值、平均值、首末记录变化百分比，以及按时间倒序的测量历史；不同单位指标分卡片绘制，避免共用错误量纲。
- **响应兼容**：趋势响应仍由 Swagger 声明为通用 `pkg.Response`，解析器兼容直接 points、按指标分组、编码映射和平铺记录结构；空数据、单点、相同值及非数值记录均有安全展示。
- **病史记录**：列表标题展示记录数，展开行使用结构化字段展示完整记录，补充过敏反应、治疗情况和备注等文本信息。
- **慢病专病**：按当前接口列表计算管理中、需重点关注和已终止数量；合并病种名称与编码，评估详情改用结构化字段和嵌套卡片。
- **目标与方案**：优化名称、ID、状态和时间的信息层级；目标展开内容及方案详情由原始 JSON 改为通用结构化字段展示，状态值和未定义字段不虚构中文枚举。
- **通用数据展示**：新增 `DataView`，支持对象、数组、原始值、常见时间字段和中英文字段标签，嵌套数据使用 Descriptions、Tag 和 Card 展示。

### 接口限制

1. 趋势接口仅明确 `points` 按测量时间升序，响应精确字段仍未建模；当前解析器做结构兼容，仍需真实响应样本验证。
2. 非数值测量值不参与折线及统计计算，历史趋势需要接口返回可转换为数字的 `metric_value`。
3. 示例图中的参考范围、健康结论和部分汇总字段没有接口依据，本次未补造这些业务数据。
4. 本次未连接真实后端进行接口和浏览器交互联调。

## 任务3：健康档案会员概要、枚举渲染与慢病专病重构

- 时间：2026-11-11
- 执行人：Kimi@Trae
- 类型：接口类型 / 表单优化 / 慢病专病 / 评估记录

### 任务描述

依据健康档案 `overview.member`、`enum-options` 和慢病专病接口补充档案信息展示，优化主档案、生活习惯及病史枚举字段，重构慢病卡片、关联指标和评估记录，并移除新建专病中的评估指标录入。

### 技术方案

- **固定会员信息**：档案详情 Tabs 上方展示接口返回的年龄、性别、生日和联系电话，不补充接口未返回的会员资料。
- **枚举字典**：新增 `getHealthArchiveEnumOptions` 和统一文案解析函数；主档案、生活习惯使用字典 Select，过敏史、既往疾病史、家族史和手术史同步优化表格文案及编辑控件；无字典的数值字段继续使用 InputNumber。
- **慢病卡片**：按专病条目展示病种、编码、控制状态、风险摘要、评估次数、最近评估、治疗情况和备注；卡片操作与卡片选中分离，支持状态筛选和包含已终止。
- **关联指标**：选中卡片后按病种编码请求专病指标字典，解析并用 Table 展示名称、编码、单位、数据类型、必填、选项、分组和排序。
- **评估时间线**：评估记录使用 Timeline 展示时间、批次、评估人、指标数、摘要和来源，保留分页、结构化详情及按动态指标定义编辑；时间线、详情和关联指标表均限制自身滚动。
- **新建专病**：仅保留病种、诊断日期、评估日期、来源和备注，不再请求创建用字典或提交 `metrics`。
- **类型修正**：区分评估列表响应与更新请求的可选字段；会员指标记录列表复用 `ArchiveMetric` 类型。

### 接口与 UI 差异

1. Swagger 新建专病摘要仍描述为“新建专病条目并录入当次评估”，参数说明仍写 `metrics` 必填，但请求模型没有声明 `required`，本次 UI 按需求移除指标并不提交 `metrics`，需后端确认允许无指标建档。
2. Swagger 慢病状态查询说明仍为“控制良好/基本控制/控制不佳/急性加重期”，最新档案类型注释为“管理中/稳定/未达标/高风险”，当前 UI 按新类型注释渲染，建议后端统一文档口径。
3. 专病指标字典响应在 Swagger 中仍为通用 `pkg.Response`，当前保留多层结构解析，精确层级及字段需真实响应样本确认。
4. 本次未连接真实后端进行接口和浏览器交互联调。

## 任务4：健康档案竖向 Tabs、列表滚动与卡片密度优化

- 时间：2026-11-11
- 执行人：Kimi@Trae

- **小表格**：健康档案列表、四类病史、指标记录、关联指标、健康目标和健康方案共 6 类 Table 全部设置为 `size="small"`。
